### About

This is a remake of the [original website](https://github.com/yaseen-ahmed26/biscuit-website) for the Biscuit (now renamed to Peck) platform that was made with vanilla JavaScript/HTML/CSS. This new website has been made with SvelteKit instead. It has also been redesigned.

The old project got difficult to maintain due to lots of repeated logic (e.g. HTML structures) and separated logic (.js, .html).

SvelteKit was chosen because it stays largely close to regular JavaScript/HTML/CSS except it bundles the 3 into a single file. This means there is no jumping between scripts, and the CSS you write in that file will only affect that HTML. Runes in particular have been helpful for updating UI and logic at the same time. The learning curve for SvelteKit was also very small.
